# AutoReach 月度广告预算预分配

同一车行、同一月份的多个活动共享 ZIP 投放上限。理想分配值以万分之一
美分给出，账本只能记录整数美分；本组件在所有满足约束的取整方案中，
给出总误差最小的那一个。

## 接口

```go
res, ok := autoreach.Allocate(campaigns, zipCaps)
```

- `Campaign{ID, Budget, Ideals}`：`Budget` 为整数美分；`Ideals` 为各目标
  ZIP 的理想值（万分之一美分），其和恰为 `Budget*10000`。
- `zipCaps`：每个 ZIP 的整数美分投放上限。
- 返回 `Result{Allocations, TotalError}`；`ok=false` 表示不可行。

## 正确性依据

每条 (活动, ZIP) 关系的实际金额只能是理想值的 floor 或 ceil。先取全部
floor 作为基线，则：

- 活动 c 的实际总和要等于预算，还需再分配 `k_c = (Σ 理想值小数部分)/10000`
  个整数美分（由理想值之和恰为预算×10000 可知 `k_c` 是非负整数），且每个
  关系至多再承担 1 美分；
- 某关系多承担 1 美分时，误差从 `r` 变为 `10000-r`（`r` 为小数部分），
  增量费用为 `10000-2r`（可为负）；
- ZIP 的剩余容量为 `上限 - 基线`，基线为负即不可行。

于是问题精确化为最小费用流：源→活动（容量 `k_c`，费用 0），活动→ZIP
（容量 1，费用 `10000-2r`），ZIP→汇（容量剩余容量，费用 0）。能推送满
`Σk_c` 当且仅当原问题可行；流量与取整方案一一对应，流的费用与总误差
只差常数 `Σr`，故最小费用流给出总误差最小的方案。实现为 SPFA 最短路
增广，天然支持负费用边，且所有容量为整数，增广结果必为整数流。

## 复杂度

设 C 为活动数、Z 为 ZIP 数、R 为目标关系总数。

- 时间：增广次数 ≤ Σk_c ≤ R，每次 SPFA 为 O(V·E)，V = C+Z+2、
  E = O(C+R+Z)，总体 O(R·(C+Z)·(C+R+Z))。
- 空间：O(V+E) = O(C+R+Z)。
