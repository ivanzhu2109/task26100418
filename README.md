# AutoReach 月度广告预算预分配

Go 库：为同一车行、同一月份的多个活动，在共享 ZIP 上限下把整数美分预算
分配到各目标 ZIP，使实际金额相对理想值（万分之一美分）的总误差最小。

## 接口

```go
plan, ok := autoreach.Allocate(campaigns, zipCaps)
```

- `Campaign{ID, Budget, Ideals}`：`Budget` 为整数美分；`Ideals[zip]` 为万分之一
  美分的理想分配值，同一活动的理想值之和恰为 `Budget*10000`。
- `zipCaps`：每个 ZIP 的整数美分投放上限。
- 返回 `Plan{Amounts, TotalError}`；不存在满足约束的方案时 `ok == false`。

## 正确性依据

对每条 (活动, ZIP) 关系，理想值 `v = floor*10000 + r`（`0 ≤ r < 10000`）：

- `r == 0` 时金额固定为 `floor`（理想值已是整数美分，不得改变）；
- 否则金额为 `floor + y`，`y ∈ {0,1}`：向下取整误差 `r`，向上取整误差
  `10000 - r`。

由于同一活动的理想值之和恰为 `Budget*10000`，活动 `c` 需要进位的次数是定数
`k_c = Budget - Σfloor`；ZIP `z` 的剩余容量为 `u_z = cap_z - Σfloor`（若小于 0
则直接不可行）。于是原问题精确等价于：

> 每个活动恰好选择 `k_c` 条关系进位，每个 ZIP 被选中的次数不超过 `u_z`，
> 最小化 `Σ y·(10000 − 2r)`（总误差 = 常数 `Σr` + 该值）。

这是二分图上的最小费用流：源→活动（容量 `k_c`，费用 0）、活动→ZIP（每条关系
一条边，容量 1，费用 `10000 − 2r`）、ZIP→汇（容量 `u_z`，费用 0）。流量达到
`Σk_c` 的最小费用流一一对应最优取整方案；最大流不足 `Σk_c` 当且仅当约束不可
同时满足（不可行）。实现用 SPFA 逐路增广，允许负费用边（`r > 5000` 时进位反而
降低误差），结果天然为整数流。测试中对固定种子的微型输入用穷举核对可行性与
最小误差，并另设共享 ZIP 需重新分配、联合容量不足判不可行两个针对性用例。

## 复杂度

设关系数 `E`（所有活动的目标 ZIP 条目总数）、节点数 `V = 活动数 + ZIP 数 + 2`。
增广次数等于总流量 `Σk_c ≤ E`，每次 SPFA 为 `O(V·E)`：

- 时间：`O(E² · V)`；
- 空间：`O(V + E)`。
